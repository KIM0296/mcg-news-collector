# MCG 주간 원자력 기사 수집기 (v1.0)

매주 원자력 기사를 모아 **브리프 GPT에 바로 넣을 수 있는 엑셀**(국내외단신DB-MCG-YYYYMMDD.xlsx)을 만듭니다.

## 수집 출처

| 출처 | 가져오는 것 | 상태 |
|---|---|---|
| KAIF 투데이뉴스 | 국내기사, 세계기사, 사설/칼럼/기고 (원자력계 소식은 `--notices`로 선택) | 작동 |
| World Nuclear News | 그 주 전체 기사 + 분류 + 첫 문단 요약 (팟캐스트·특집 제외) | 작동 |
| K-NEISS 세계원전시장동향 | 해외 단신 (NucNet, Platts 등의 한국어 요약) | **설정 대기**: 출처와 로그인 필요 여부 확인 후 `mcg_collect/sources/kneiss.py`만 채우면 됨 |

- 같은 기사(같은 링크)는 1건만 남깁니다. KAIF에 다시 실린 WNN 기사는 WNN 원본을 남깁니다.
- '관련국가'는 제목·요약의 국가명으로 자동 추정합니다.
- '핵심 키워드'는 비워 둡니다. 브리프 GPT(v1.4)가 제목과 요약을 보고 채웁니다.
- 기존 엑셀의 7개 열 뒤에 **'원문 요약'** 열을 추가했습니다(WNN 첫 문단). GPT가 근거 확인용으로 씁니다.

## 5월 1주차 검증 결과
기존 엑셀(인턴 작성)과 비교한 결과입니다.
- KAIF 기사 15건 중 15건, WNN 기사 13건 중 13건을 **모두** 찾았습니다.
- 인턴이 빠뜨린 기사 13건을 추가로 찾았습니다(5월 8일 WNN 5건 등).
- 해외 단신 16건은 K-NEISS를 설정하면 들어옵니다.

## 쓰는 방법 (세 가지 중 선택)

### 방법 1. MCG 컴퓨터에서 직접 실행 (윈도우)
1. 파이썬을 설치합니다. python.org에서 내려받고, 설치 화면에서 **"Add python.exe to PATH"**에 체크하세요.
2. 이 폴더의 `설치_처음1회.bat`을 더블클릭합니다. 처음 한 번만 하면 되고, 5분 정도 걸립니다.
3. 매주 월요일에 `실행.bat`을 더블클릭하면 `결과` 폴더에 엑셀이 생깁니다.
4. 엑셀을 브리프 GPT에 첨부하고 "시작"을 입력합니다.

명령어로 실행하는 방법도 있습니다.
```
python collect.py                     # 지난주
python collect.py --week 2026-05-04   # 특정 주
python collect.py --only wnn          # 특정 출처만
```

### 방법 2. 매주 자동 실행 (GitHub, 무료)
1. MCG 명의 GitHub 계정에 저장소를 만들고 이 폴더를 그대로 올립니다.
2. `.github/workflows/weekly-collect.yml` 설정에 따라 **매주 월요일 오전 7시**에 저절로 수집되고, 결과가 `data/` 폴더에 저장됩니다.
3. 바로 실행하고 싶을 때는 저장소 → Actions → weekly-collect → **Run workflow**를 누릅니다.
4. K-NEISS 로그인이 필요해지면 저장소 Settings → Secrets에 `KNEISS_ID`, `KNEISS_PW`를 넣습니다. 계정 정보는 파일에 적지 않습니다.

### 방법 3. GPT와 직접 연동 (방법 2 + 설정 5분)
방법 2를 설정한 뒤, 브리프 GPT 편집 → 구성 → **작업(Actions) → 새 작업 만들기**로 들어가 `gpt_action_openapi.yaml` 내용을 붙여 넣습니다. 이때 `{OWNER}/{REPO}`는 실제 저장소 이름으로 바꾸고, 인증은 '없음'으로 둡니다.
→ 이제 엑셀 없이 GPT에 **"시작"**만 입력하면 GPT가 이번 주 수집 결과를 직접 가져와 PDF까지 만듭니다.

> 참고: 이 방식은 저장소가 **공개(public)**여야 GPT가 읽을 수 있습니다. 올라가는 것은 공개 기사의 제목과 링크뿐이에요. 비공개로 두려면 별도 인증 설정이 필요합니다.

## 문제가 생기면
- **"KAIF 수집 실패"**: KAIF 사이트 구조가 바뀌었거나 일시적인 접속 문제입니다. 나머지 출처로는 엑셀이 만들어집니다. 반복되면 `mcg_collect/sources/kaif.py`를 점검하세요.
- **KAIF는 브라우저(Chromium)를 띄워 읽습니다.** 사이트가 처음 응답에 내용을 비워 보내기 때문입니다. 그래서 `설치_처음1회.bat`에 브라우저 설치가 들어 있습니다.
- **사이트 부담을 줄이려고** 요청 사이에 1초씩 쉽니다. 한 주 수집에 2~4분 정도 걸립니다.
