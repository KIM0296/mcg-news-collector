# MCG 자체 영상·사진 모음

여기에 올린 영상(mp4, mov)과 사진(jpg, png, webp)은 쇼츠를 만들 때 **가장 먼저** 쓰입니다.
쇼츠 대본의 '영문 검색어'와 **파일 이름에 같은 단어가 많을수록** 그 장면에 들어갑니다.

## 파일 이름 짓는 법
영문 단어를 하이픈(-)으로 잇고, 원하면 밑줄(_) 뒤에 한글 설명을 붙입니다.
- `nuclear-power-plant-aerial_원전항공.mp4`
- `cooling-tower-steam_냉각탑.jpg`
- `uranium-fuel-pellet_핵연료.jpg`
- `business-meeting-government_회의.mp4`
- `construction-site-crane_건설현장.mp4`

## 주의
- **MCG가 쓸 권리가 있는 자료만** 올려 주세요. 직접 찍은 사진, 구매한 자료, 상업적 이용이 허용된 무료 자료 등이 해당합니다. 언론사 사진이나 다른 회사 홍보 영상은 올리지 않습니다.
- 사진은 화면에서 천천히 옆으로 흐르는 효과가 들어갑니다. 가로 사진(1600px 이상)이 좋습니다.
- 파일 하나는 50MB 이하로 올려 주세요.
